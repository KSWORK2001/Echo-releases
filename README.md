# Echo Releases

Official installers and the auto-update feed for **Echo**, the on-screen AI meeting copilot.

## Install

Grab the installer for your platform from the [latest release](https://github.com/KSWORK2001/Echo-releases/releases/latest):

- **Windows:** `Echo_<version>_x64-setup.exe` or the `.msi`
- **macOS:** `Echo_<version>_aarch64.dmg` (Apple Silicon) or `Echo_<version>_x64.dmg` (Intel)
- **Linux:** `.AppImage`, `.deb`, or `.rpm`

## Updating

Echo updates itself. Use **Check for updates** inside the app, it reads `latest.json` from this repository and installs new versions in place.

This repository hosts release assets only. The application source is maintained privately.
